# Security

## Supported versions

Security fixes are applied to the latest release line. Use the newest published versions of `jest-canvas-mock-compare` and `jest-canvas-mock-compare-viewer`.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for undisclosed security problems.

1. **GitHub:** If this repository is hosted on GitHub and [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) is enabled, use that flow.
2. **Email:** Contact the maintainers privately at **security@grafana.com** and follow the instructions on https://github.com/grafana/grafana?tab=security-ov-file#email

## Confidentiality

Reports are handled confidentially. Maintainers will coordinate an advisory or release note when a fix is ready.
